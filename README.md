## ローカル確認方法

このリポジトリをクローンしたあと、`index.html` をブラウザにドラッグ＆ドロップするだけで動作します。または、ローカルサーバーで確認したい場合：

```bash
# Python が入っている環境で
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

## GitHub Pages へのデプロイ

このリポジトリはそのまま GitHub Pages として公開できます。

1. GitHub上のリポジトリ Settings → Pages に進む
2. Source：`Deploy from a branch`
3. Branch：`main` / Folder：`/ (root)` を選択
4. `Save` をクリック
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開

### 独自ドメインを使う場合

リポジトリのルートに `CNAME` ファイル（中身は `awasanga.com`）を追加し、Settings → Pages の Custom domain で設定してください。`.nojekyll` ファイルが既に置いてあるので、Jekyll処理はスキップされます。

## 実装に関する Notes

### 確定済みの設計

**ヒーローキャッチコピー** … 「会いに行ける、山のなかま。」（親しみ・人寄り）
**KPI 4数字** … 来場者 6,174人／林道通行量 約15,400台/年／連携拠点 2／メディア・パートナー 6団体
**キャラクター設定** … 公式バイブル（木頭図書館謎解きイベント由来）に準拠

### 要記入の箇所

実数値・連絡先・組合員氏名など、現時点で未確定の箇所は HTML 内に「要記入」のラベルで表示されています。確定したものから順に置き換えてください。

主な「要記入」項目：

- 営業時間・定休日・駐車場情報（`facility-okuyarito.html`、`facility-hiranosato.html`）
- 所在地・電話・メール（全ページのフッター、`contact.html`）
- ルート所要時間・難易度（`trail-guide.html`）
- 組合員氏名・役職（`about.html`）
- 広報誌バックナンバー発行日・PDFリンク（`projects.html`）
- 各プロジェクトの数値（整備した稜線、参加人日 など）
- Instagram公式アカウントURL
- パートナー6団体の正式ロゴ画像
